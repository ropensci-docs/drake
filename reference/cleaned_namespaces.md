# Auxiliary storr namespaces **\[deprecated\]**

2019-02-13

## Usage

``` r
cleaned_namespaces(default = storr::storr_environment()$default_namespace)
```

## Arguments

- default:

  Name of the default `storr` namespace.

## Value

A character vector of `storr` namespaces that are cleaned during
[`clean()`](https://docs.ropensci.org/drake/reference/clean.md).
