# Run a function in debug mode. **\[stable\]**

Internal function for
[`drake_debug()`](https://docs.ropensci.org/drake/reference/drake_debug.md).
Not for general use.

## Usage

``` r
debug_and_run(f)
```

## Arguments

- f:

  A function.

## Value

The return value of `f`.
