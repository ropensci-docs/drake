# List the old drake triggers. **\[deprecated\]**

Triggers are target-level rules that tell
[`make()`](https://docs.ropensci.org/drake/reference/make.md) how to
know if a target is outdated or up to date.

## Usage

``` r
triggers()
```

## Value

A character vector with the names of the old triggers.
